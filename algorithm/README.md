# WisePanda training and validation

Install dependencies:
```sh
pip install -r requirements.txt
```

## dataset
dataset storage in the `dataset/` folder
The training data generated by the physical model is `dataset/vector_reallike_6000.npy`.
`dataset/vector_real_118_patch.npy` and `dataset/vector_real_335_patch.npy` correspond to the real manually assembled bamboo slip and wooden tablet datasets bamboo236 and wood670, respectively. `dataset/interference_data_bamboo.npy`, `dataset/interference_data_bamboo_bottom.npy`, `dataset/interference_data_wood.npy` and `dataset/interference_data_wood_bottom.npy` are the extended datasets for bamboo slips and wooden slips, respectively. Usage methods can be referenced in the compare_methods.ipynb file. Their purpose is to expand the selection pool during model assembly and test the model's robustness.

## train
The training process is orchestrated by the main training script `train.py`, which integrates data loading, model training, and optimization workflows.

## Validation
Model validation and performance comparison are conducted through the comprehensive analysis notebook `compare_methods.ipynb`.
